# CLI Install

Install the project locally from the repository root:

```bash
pip install -e .
```

After installation, use the short command:

```bash
hausa --version
hausa new python app.hausa
hausa run app.hausa
hausa to-en app.hausa -o app.py
hausa keywords python
```

The old wrapper remains available:

```bash
python h-run.py --version
python h-run.py run app.hausa
```
